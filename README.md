## 🛠 **Adding New Certifications**

1. **Add the certificate file** to the appropriate issuer folder under `certifications/`
2. **Update `certifications.json`** with the new certification metadata
3. **Update this README** with the new entry in the appropriate table
4. **Commit changes** with a descriptive message
